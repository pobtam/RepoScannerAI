# The original prototype

`report-browser-prototype.jsx` is the interaction and visual reference the
report-browser specification was written against. It is **not** the
application: it holds no real data, talks to no API, and none of its numbers
mean anything.

The application is in `../reportui`, built against the real API. The prototype
is kept here because it is the record of what the interface was meant to feel
like, and because a specification's illustrations are worth keeping next to the
thing they described.

To look at it:

    cd prototype
    npm install
    npm run dev
